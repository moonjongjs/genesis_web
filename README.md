# GENESIS · 프리미엄 자동차 웹 포트폴리오

> 풀스크린 이미지 캐러셀과 차량별 랜딩 페이지로 표현한 제네시스 브랜드 웹사이트 프로젝트

차량의 외관과 실내 이미지를 화면 가득 배치하고, 절제된 타이포그래피와 부드러운 움직임으로 프리미엄 브랜드의 분위기를 표현했습니다. 메인 화면에서 차량을 탐색한 뒤 상세 페이지에서 이미지, 제원, 예시 가격을 확인하는 흐름으로 구성했습니다.

**HTML5 · CSS3 · Vanilla JavaScript · 반응형 레이아웃**

## 03. 기획 의도와 디자인

### 이미지 중심의 첫인상

차량 사진이 화면 전체를 채우도록 구성해 브랜드와 제품에 시선이 집중되도록 했습니다. 이미지에는 `object-fit: cover`를 적용하고, 텍스트 영역에는 그라데이션과 그림자를 사용했습니다.

### 절제된 색상과 타이포그래피

블랙과 화이트를 중심으로 화면을 구성하고 넓은 여백, 큰 제목, 얇은 구분선을 활용했습니다. 상세 페이지에서도 같은 색상과 타이포그래피 방향을 유지해 메인 화면과의 연결감을 주었습니다.

### 탐색에서 정보 확인으로 이어지는 흐름

**메인 비주얼 탐색 → 슬라이드 선택 → 차량별 상세 페이지 → 제원·예시 가격 확인**

메인에서는 이미지에 집중하고, 상세 페이지에서는 필요한 정보를 순차적으로 확인하도록 구성했습니다.

## 05. 주요 기능

| 기능 | 구현 내용 |
| --- | --- |
| 자동재생 | 약 4초간 표시한 후 다음 슬라이드로 전환 |
| 무한 순환 | 첫 슬라이드와 마지막 슬라이드의 복제본을 이용해 양방향 순환 |
| 수동 탐색 | 이전·다음 버튼, 키보드 좌우 방향키 지원 |
| 드래그·스와이프 | Pointer Events로 마우스 드래그와 터치 입력 처리 |
| 클릭과 드래그 구분 | 이동 거리를 기준으로 상세 페이지 열기와 슬라이드 이동 구분 |
| 진행 상태 표시 | 현재 슬라이드 번호와 자동재생 진행 표시줄 제공 |
| 상세 페이지 연결 | 슬라이드 선택 시 해당 상세 페이지를 새 탭으로 열기 |
| 콘텐츠 변경 | URL의 `slide` 값을 읽어 이미지·차량명·제원·예시 가격 설정 |
| 스크롤 등장 효과 | `IntersectionObserver`로 섹션이 화면에 들어올 때 표시 |
| 패럴럭스 | 스크롤 위치에 따라 배경 이미지를 이동 |
| 상단 이동 | 스크롤 후 나타나는 버튼으로 페이지 상단 이동 |
| 반응형 구성 | 미디어 쿼리와 `clamp()`로 화면 크기에 맞춰 배치·글자 크기 조정 |

슬라이드에는 대체 텍스트와 키보드 포커스를 적용하고, 탐색 버튼에는 접근성 이름을 지정했습니다. 포커스된 슬라이드에서 Enter 또는 Space 키로 상세 페이지를 열 수 있습니다.

## 06. 상세 페이지 구성

| 순서 | 섹션 | 역할 |
| --- | --- | --- |
| 1 | 히어로 | 선택한 차량 이미지와 모델명, 소개 문구 표시 |
| 2 | Specifications | 차량별 제원 또는 실내 특징을 그리드로 안내 |
| 3 | 브랜드 비주얼 | 패럴럭스 이미지와 브랜드 메시지 표현 |
| 4 | Price | 교육용 예시 가격 표시 |
| 5 | 탐색 링크 | 메인 화면으로 돌아가기 및 상단 이동 |

하나의 `landing.html`을 공유하고 JavaScript 데이터로 내용을 바꿉니다. 예를 들어 `landing.html?slide=2`는 두 번째 슬라이드에 연결된 콘텐츠를 표시합니다.

## 07. 기술 구현 포인트

### 자연스럽게 이어지는 캐러셀

슬라이드 목록 앞뒤에 마지막·첫 번째 슬라이드의 복제본을 배치했습니다. 전환이 끝나면 실제 슬라이드 위치로 애니메이션 없이 이동해 순환이 이어지도록 구현했습니다.

### 입력 의도를 구분하는 인터랙션

포인터 이동 거리가 10px 이하이면 클릭·탭으로 판단하고, 55px 이상이면 슬라이드를 전환합니다. 그 사이의 짧은 드래그는 현재 슬라이드 위치로 복귀하도록 구성했습니다.

### 데이터 기반 상세 페이지

이미지, 제목, 설명, 제원, 가격을 배열에 정리했습니다. URL 파라미터에 따라 데이터를 선택하므로 차량마다 HTML 파일을 따로 작성하지 않아도 됩니다.

### 스크롤에 반응하는 화면

섹션 등장 감지는 `IntersectionObserver`를 사용하고, 패럴럭스 계산은 `requestAnimationFrame`으로 처리했습니다. 스크롤 이벤트에는 `passive: true`를 적용했습니다.

## 09. 실행 방법

1. 프로젝트 전체 파일을 다운로드합니다.
2. `index.html`을 브라우저로 엽니다.
3. 자동재생 또는 이전·다음 버튼으로 이미지를 탐색합니다.
4. 차량 이미지를 클릭해 상세 페이지를 확인합니다.

별도의 패키지 설치나 빌드 과정 없이 실행하는 정적 웹 프로젝트입니다.

GitHub에 업로드할 때는 `README.md`를 `index.html`과 같은 위치에 두고, `css`, `js`, `images` 폴더를 함께 업로드합니다. README의 이미지는 `./images/파일명` 형태의 상대 경로로 연결됩니다.
