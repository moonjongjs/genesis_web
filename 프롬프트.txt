1. 메인 페이드인 페이드아웃 슬라이드
   프로젝트 : 메인 페이드인 페이드아웃 슬라이드 자동재생 슬라이드 제작
   - 반응형 : 모바일, 태블릿, 데스크탑
   - 퍼블리셔 : Moon Seon Jong
   - 제네시스 자동차 이미지는  업로드한 이미지로 사용
   - 너비 창너비 가득
   - 높이 창높이 가득
   - 한화면에 1개씩 페이드인 페이드아웃 부드럽게 전환되는 애니메이션
   - 전환시간 1초
   - 대기시간 4초   
   - 해당 슬라이드 이미지 마우스 클릭시 랜딩페이지로 이동
   - 좌측, 우측 화살버튼 디자인 배치
   - 좌측 < 화살버튼 클릭시 이전슬라이드 구현
   - 우측 > 화살버튼 클릭시 다음슬라이드 구현
   - 데스크탑 : 마우스 드래그앤드드롭(마우스 끌기 & 놓기) 구현
   - 모바일 : 핑거 터치 이벤트 구현
   - 마우스 이벤트 & 터치 이벤트 없으면 슬라이드 자동 실행
   - 슬라이드 이미지 8개 사용
     slide01.png, slide02.png, slide03.png, slide04.png, slide05.png, slide06.jpg, slide07.jpg, slide08.jpg

2. 랜딩페이지 구성
   - 랜딩페이지는 상단에 풀스크린 반응형 해당 자동차 모델 사진으로 배치
   - 랜디페이지 로딩시 자동차 모델 텍스트 타이틀 애니메에이션 구현
   - 랜딩페이지는 스무스스크롤 이벤트구현, 패럴럭스 구현(트랜지션은 2초이상)
   - goTop 버튼 이벤트 구현
   - 아래는 자동차 제원과 가격으로 콘텐츠 제작
   - 메인슬라이드로 돌아가기 버튼을 만들어 구현
